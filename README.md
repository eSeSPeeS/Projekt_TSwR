# Projekt_TSwR

## Model Predictive Control z Gaussian Process dla symulowanego samochodu

**Cel projektu**  
Stworzenie symulatora samochodu w oparciu o model dynamiczny opisany w publikacji naukowej arXiv:2003.04882.  
Zaimplementowanie regulatora typu Model Predictive Control (MPC) z Gaussian Process, który umożliwi śledzenie zadanych trajektorii ruchu pojazdu.

## Milestones

1. Stworzenie symulatora samochodu
2. Implementacja MPC
3. Implementacja Gaussian Process'u do MPC

## Technologie

Projekt został zrealizowany w języku Python z wykorzystaniem:
- matplotlib – wizualizacja wyników  
- acados – implementacja regulatora MPC
